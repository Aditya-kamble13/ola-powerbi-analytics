# Ola Ride Analytics Dashboard

An end-to-end interactive Power BI dashboard analyzing over 100,000 ride-hailing booking records to derive operational insights on revenue, cancellations, and customer payment behavior.

## 📊 Dashboard Preview
![Dashboard Preview]("C:\Users\adity\OneDrive\Desktop\Ola-PowerBI-Project\Screenshot 2026-09-29 112901.png")

## 🔑 Key Features & Insights
- **Revenue Breakdown**: Evaluated total revenue across vehicle types (Sedan, Mini, Bike, Auto) and payment modes (UPI, Cash, Cards).
- **Cancellation Analysis**: Identified primary reasons behind customer and driver cancellations to improve fulfillment rate.
- **Dynamic Filtering**: Integrated multi-variable slicers for real-time region-wise and status-wise data slicing.

## 🛠️ Tools Used
- **Power BI Desktop** (Data Visualization & Dashboard Design)
- **Power Query** (ETL, Data Cleaning & Type Formatting)
- **DAX** (Custom Measures for Total Revenue, Total Bookings, and Cancellation Metrics)
